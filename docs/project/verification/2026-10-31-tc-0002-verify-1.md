**F5. Cenário real executa hooks da configuração Git global - severidade média**

- **Código atacado:** [test/herdr/scenario.ts:39](/Users/fael/workspaces/github/faelplg/demerzel/test/herdr/scenario.ts:39). O servidor recebe `HOME` e `SHELL` do chamador, sem o isolamento Git criado pelo sandbox em `test/core/helpers/sandbox.ts:33-45`.
